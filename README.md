# 統計トリ🦜

個人や仲間内で「ちょっとした統計」を記録・予想するPWA風ウェブアプリ。
仕様は [SPEC.md](SPEC.md) を参照。

## 使い方

`index.html` をブラウザで開くだけ(サーバー不要・データは端末内に保存)。
GitHub Pages 等で公開すると、スマホの「ホーム画面に追加」でアプリのように使えます。

- **新規統計**: タイトルとボタン(選択肢2つ以上)を決めるだけ
- **記録**: ホームのカードのボタンを1タップ
- **0タップ記録**: 設定画面の「クイック記録URL」をホーム画面アイコンにすると、開いた瞬間に記録完了
- **予想**: 記録1件目から表示。精度自信メーター(🥚→🐣→🐤→🦜)が記録のたびに育ちます
- **グラフ**: 時間帯 / 曜日×時間帯(ヒートマップ)/ 月の日付 を切り替え
- **バックアップ**: JSON書き出し・読み込み(マージ)対応
